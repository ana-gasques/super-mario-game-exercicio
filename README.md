# Super Mario Bros Game 
Projeto desenvolvido com HTML, CSS e JavaScript inspirado no universo do Super Mario. O objetivo é desviar dos obstáculos e desenvolver habilidades nas linguagens.

🚀 Tecnologias Utilizadas:
HTML5
CSS3
JavaScript
🚀 Ações utilizadas:
Movimentação do Mario
Sistema de colisão com obstáculos
Animações utilizando CSS
